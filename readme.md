# Python Pro M10L1
## Esta es la idea de mi proyecto:
> Crear una síntesis de voz que describa los cambios climáticos.
Audio voz incluido.
Causas y consejos.
Historial de eventos.
Cómo prevenirlos.
Información educativa.

Tipo de proyecto + análisis(Eco-calculadora).

Tipo de proyecto:
Aplicación web interactiva que permite a los usuarios calcular su huella de carbono y recibir recomendaciones personalizadas para reducirla.

Enfoque educativo y ambiental: concienciar sobre el impacto de las actividades diarias.
Tecnología base: HTML, CSS, Flask (Python) y GitHub para control de versiones.

Análisis del proyecto


- 1. Conceptos básicos del diseño web:
Estructura: HTML, CSS y diseño responsivo.
Usabilidad: interfaz clara, botones visibles, formularios fáciles de completar.
Accesibilidad: colores con buen contraste, etiquetas para lectores de pantalla.


- 2. HTML + CSS:
HTML:
Formulario para ingresar datos (transporte, consumo eléctrico, alimentación).
Secciones para mostrar resultados y consejos.
CSS:
Diseño limpio y moderno.
Uso de flexbox o grid para organizar elementos.
Paleta de colores verdes y azules para transmitir sostenibilidad.


- 3. GitHub + IDE:
GitHub:
Repositorio para almacenar código y documentación.
Uso de ramas para nuevas funciones.
IDE:
Visual Studio Code o PyCharm para desarrollo.
Extensiones para Python, HTML y control de versiones.
